# 提示词编写技能

## 通用结构模板（按需取用，不必全塞）
```
# 角色
你是<身份>，擅长<能力边界>
# 任务
<一句话目标>
# 约束
- 硬性要求（格式/长度/禁词）
- 语气与风格
# 输出格式
<结构示例>
# 示例
输入：… 输出：…（1-3组足够）
```

## 提效技巧
1. 任务复杂→拆成步骤让它按步走；简单任务别加步骤（过约束）
2. few-shot 示例比形容词有用："写得活泼"不如贴一个活泼的例子
3. 给输出骨架（"先给结论，再列三点依据"）
4. 长任务加自检："完成后检查是否遗漏 N 项要求"

## 反模式（看到就改）
- "请你作为一个…"后面堆十个身份 → 保留最相关的1-2个
- "要求：认真、细心、高质量" → 删（空话，换成可验证的具体要求）
- 全指令一句话不换行 → 拆段
- 既要说格式自由又要固定格式 → 二选一
- 角色扮演设定写小说背景但不写说话风格 → 补"说话时…"行为句

## 优化他人提示词的流程
1. 指出问题（对应反模式）
2. 给改写版（结构模板）
3. 附一句"改了什么、为什么"
